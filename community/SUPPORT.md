# Getting help

| You want to… | Do this |
|---|---|
| Ask how to use something | Open an issue with the **Question** form |
| Report a bug | Open an issue with the **Bug report** form |
| Suggest a feature | Open an issue with the **Feature request** form |
| Report a security problem | Follow [SECURITY.md](SECURITY.md), never a public issue |
| Report a Code of Conduct concern | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Read the repository's README first: it is the main documentation. Support is best effort by
one maintainer, with no guaranteed response time.
