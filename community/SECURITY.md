# Security policy

## Supported versions

Only the latest commit on the default branch is supported. Where a repository publishes
releases, only the latest release is supported.

## Reporting a vulnerability

**Do not open a public issue.** Report it privately through GitHub:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and its impact.

Only the maintainer sees the report. The maintainer aims to acknowledge it within 7 days,
then works with you on a fix and on when to disclose it. Credit is given in the published
advisory unless you ask otherwise.

## Scope

In scope: code and configuration in @OWNER@'s repositories. Out of scope: third-party
dependencies (report those upstream) and issues that need physical access to a machine.
